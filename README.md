# Cardiovascular Simulator App

Case search for a cardiovascular simulator: case-insensitive substring match over name, categories and chief complaints, exact case-number and `PREFIX-123` lookups, AND/OR filters and sorting.

- `src/search/caseSearch.js`: framework-agnostic search core
- `src/data/sampleCases.js`: placeholder data
- `index.html`: demo page

`npm test` runs the unit tests. `npm start` serves the demo locally.
